# 📰 The Campus Chronicle

> **Your Campus. Your Stories. Your Voice.**

A modern, fully responsive college digital newspaper website built with pure HTML, CSS, and JavaScript.

## ✨ Features

- 🗞️ Professional newspaper layout with featured hero article
- 🔴 Live breaking news ticker banner
- 🔍 Real-time article search overlay
- 📂 Category filtering (Campus News, Technology, Sports, Culture, Student Life)
- 📖 Full article detail modal with social sharing
- 📅 Upcoming events sidebar
- 🔥 Trending & Most Read sidebars
- ✉️ Email-validated newsletter subscription form
- 📱 Fully responsive (mobile, tablet, desktop)
- ♿ Accessible semantic HTML5 with ARIA support
- 🔝 Back to top button
- 🎨 Dark navy + green premium design with micro-animations

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Semantic structure |
| Vanilla CSS | Design system, animations, responsive layout |
| Vanilla JavaScript | All interactivity, no frameworks |
| Google Fonts | Playfair Display, Inter, Oswald |

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No build tools or server required.

```bash
git clone https://github.com/YOUR-USERNAME/campus-chronicle.git
cd campus-chronicle
# Open index.html in your browser
```
